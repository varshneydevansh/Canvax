# Canvax Parity Audit

This audit maps the current Canvax goal to concrete evidence in the repo.
It is intentionally strict: a passing test or shipped feature is only counted
when it covers the stated requirement directly.

## Objective

Drive Canvax from a Stitch-inspired prototype to a designer-first Codex visual
workbench that is simpler than Stitch for everyday use and more powerful for
real implementation.

## Current Verdict

Canvax is no longer just a sketch prototype. It is a local Codex visual
workbench with a strong no-API handoff pipeline, Map memory, variant branches,
generated-output binding, asset candidates, voice notes, and regression
coverage.

It is not complete against the full objective yet. The main remaining gaps are:

- true arbitrary-object infinite canvas behavior
- first-party live Codex/ChatGPT host bridges for mic, image generation, and
  continuous co-editing
- higher-fidelity production UI generation beyond deterministic local
  scaffolds
- hosted/team sharing for larger kit libraries without turning Workbench into a
  prompt-only artifact generator
- native Codex/ChatGPT registration for the read-only Canvax bridge; a local
  stdio MCP server now exists, but the host still has to register it before
  Codex or ChatGPT can call the tools directly
- real-project evidence beyond local fixtures and allowlisted project-link
  patching that manifest-listed token enforcement survives a Codex production
  port into arbitrary app files
- hosted AI visual critique and deeper motion semantics beyond static HTML/JSX
  semantic extraction, static artifact review, local screenshot palette
  sampling, local pixel-level screenshot review, local rendered DOM/layout
  review, and local design-jury aggregation
- live DOM-semantic tweak patching beyond the local Preview `Mark tweak`
  request, `codex-patch-task.json`, generated-bundle `execute-patch` proof, and
  allowlisted project-link patch proof, where a selected output region becomes
  an automatically applied edit in an arbitrary unlinked production app
- stronger default-designer UX simplification across Workbench and Advanced
